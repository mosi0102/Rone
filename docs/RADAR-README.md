# رادار خودرو (درخواست خرید)

کاربر مشخصات خودروی دلخواه را ثبت می‌کند؛ سیستم آگهی‌های مشابه/نزدیک را با **درصد تطابق** نشان می‌دهد. درخواست تا وقتی کاربر **حذفش نکند فعال می‌ماند** و آگهی‌های تازه هم سنجیده می‌شوند. نمایشگاه‌دار فهرست درخواست‌های فعال (ناشناس) را می‌بیند و آگهی مطابق خودش را پیشنهاد می‌دهد.

## مسیرها (`routes/radar.php`، با `require` در `web.php` بعد از `$lf/$listingStore`)
| مسیر | نام | کار |
|---|---|---|
| GET `/radar` | `radar.index` | رادارهای من (کارت + بهترین تطابق + تعداد جدید) |
| GET `/radar/create` | `radar.create` | فرم ثبت با پیش‌نمایش زنده |
| GET `/radar/preview` | `radar.preview` | JSON: `{count,best,top:[{title,percent}]}` با پارامترهای فرم |
| POST `/radar` | `radar.store` | ثبت ← `{id,url}` |
| GET `/radar/{id}` | `radar.show` | مشابه‌ها با درصد و دلیل هر درصد |
| DELETE `/radar/{id}` | `radar.destroy` | حذف |
| GET `/panel/radar` | `panel.radar` | (نمایشگاه‌دار) درخواست‌های خریداران + فیلتر |
| POST `/panel/radar/{id}/offer` | `panel.radar.offer` | پیشنهاد آگهی به خریدار |

نقطه‌های ورود: کارت صفحه‌ی اول، منوی «بیشتر» (کاربر و نمایشگاه‌دار)، هدر دسکتاپ، داشبورد پنل (هشدار «N خریدار دنبال خودرویی شبیه آگهی‌های شماست»).

## داده‌ی درخواست
`id, category(car|heavy|bike|bicycle), brand, model, year_from, year_to, price_max, km_max, city, color, gearbox, fuel, cc, btype, wheel, axle, note, status, created_at`
وضعیت‌ها (هم‌راستا با پنل ادمین `/admin/requests`): `active | cancelled | suspended`. خالی بودن فیلد یعنی «مهم نیست».

## الگوریتم درصد (نمونه در `$radarScore`)
فقط فیلدهای پرشده حساب می‌شوند؛ دسته‌ی نامطابق = ۰؛ زیر **۵۰٪** «مشابه» نیست (`RADAR_MIN`).
وزن‌ها: برند ۲۵ • مدل ۱۵ • قیمت ۲۰ (تا ۱۰٪ بالاتر: ۷۰٪ امتیاز، تا ۲۵٪: ۳۵٪) • سال ۱۵ (۱ سال اختلاف: ۱۰، ۲ سال: ۵) • کارکرد ۱۰ • شهر ۱۰ • هر مشخصه‌ی دیگر ۵.
درصد = امتیاز ÷ امتیاز ممکن. خروجی `notes` دلیل هر مورد (✓/⚠) را برای نمایش می‌دهد.

## اعلان (بک‌اندکار)
با ثبت/ویرایش هر آگهی: درخواست‌های فعال را بسنج؛ اگر ≥۵۰٪ بود **به کاربر** (اعلان درون‌برنامه/پیامک) و اگر آگهی مطابق درخواستی بود **به نمایشگاه‌دار** اطلاع بده (فیلد `new` = تعداد موارد جدید از آخرین بازدید).
حریم خصوصی: به نمایشگاه‌دار نام/شماره‌ی خریدار نمایش داده نمی‌شود (`خریدار ۴۶۳۰۷`)؛ ارتباط فقط از گفتگوی سامانه.
